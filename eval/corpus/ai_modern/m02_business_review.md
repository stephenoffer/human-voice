# Q3 retention review

Retention improved from 71% to 76% quarter over quarter, driven almost entirely by the onboarding changes shipped in July. The cohort that saw the new setup flow retained at 81%, compared to 68% for users who signed up the week before the change. That gap has held for eight weeks, so it is unlikely to be a novelty effect.

Where we did not make progress is the mid-market segment. Those accounts still churn at roughly twice the rate of enterprise, and exit interviews point consistently to a single cause: they cannot get their existing data in without engineering help. We have known this since March and have not prioritized it.

I would spend Q4 on the import path rather than on the features currently in the roadmap. The argument is straightforward. Mid-market represents 40% of new logos and 55% of churn, so a fix there compounds in a way that another dashboard does not. The counterargument, which the product team has made, is that import work is unglamorous and hard to demo. That is true and it does not change the arithmetic.

Risks worth flagging: the import work is estimated at six weeks and estimates in this area have historically run long. If it slips past the January renewal cluster, the effect on Q1 numbers will be muted.
